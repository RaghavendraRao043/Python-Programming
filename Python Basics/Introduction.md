# Day 1: Learn Python in 30 Days — What is Python?

Welcome to **Day 1 of the 30 Days Python Learning Challenge!**

Today, we are going to understand the basics of **Python**, why it is popular, where it is used, and how to write your first Python program.

---

## 1. What is Python?

**Python is a high-level, general-purpose programming language designed to make programming simple, readable, and easy to understand.**

Python was created by **Guido van Rossum** and was first released in **1991**.

Python is one of the most popular programming languages in the world because its syntax is simple and beginner-friendly.

### Simple Definition

> **Python is a programming language used to build software, websites, automation tools, AI applications, data science projects, and many other types of programs.**

---

## 2. Why is Python Easy to Learn?

One of Python's biggest advantages is its **simple and readable syntax**.

Many programming languages require complicated syntax and a lot of symbols. Python allows you to write code that looks close to normal English.

For example:

```python
print("Hello, World!")
```

This single line tells Python to display:

```text
Hello, World!
```

You don't need to write complicated commands just to display a message.

---

## 3. What Does `print()` Do?

The `print()` function is used to **display information on the screen**.

Example:

```python
print("Hello, World!")
```

Output:

```text
Hello, World!
```

You can also print numbers:

```python
print(100)
```

Output:

```text
100
```

You can print multiple pieces of information:

```python
print("My name is Raghu")
print("I am learning Python")
```

Output:

```text
My name is Raghu
I am learning Python
```

The `print()` function is one of the first Python concepts beginners learn.

---

## 4. Why is Python Called a High-Level Language?

Python is called a **high-level programming language** because it is designed to be easier for humans to read and write.

You don't need to directly manage computer memory or write complicated machine-level instructions for most everyday programming tasks.

For example:

```python
name = "Raghu"
print(name)
```

Python handles many low-level details behind the scenes.

This allows programmers to focus more on solving problems and building applications.

## 7. What are Python Libraries?

A **library** is a collection of pre-written code that programmers can use in their own programs.

Instead of creating everything from scratch, developers can use existing libraries to perform common or complex tasks.

For example:

```python
import math

print(math.sqrt(25))
```

Output:

```text
5.0
```

Here, the `math` library provides mathematical functionality that we can use in our program.

---

## 8. What are Python Frameworks?

A **framework** provides a structure and tools that help developers build applications.

For example:

* **Django** → Web development
* **Flask** → Web applications
* **FastAPI** → APIs and web services
* **TensorFlow** → Machine Learning and AI
* **PyTorch** → Machine Learning and AI

Frameworks can save developers significant time because they provide many common features and structures.

# 11. Your First Python Program

Let's write your first Python program.

```python
print("Hello, World!")
```

### Step-by-Step Explanation

```python
print
```

`print` is a built-in Python function used to display information.

```python
("Hello, World!")
```

The text inside the parentheses is the information we want Python to display.

```python
"Hello, World!"
```

The quotation marks tell Python that this is **text**, also called a **string**.

### Output

```text
Hello, World!
```

Congratulations!

You have written your first Python program.

# What is Python?
*  **Python** is a high-level, general-purpose programming language designed to make coding **simple and readable**.  
*   Unlike some programming languages that have **complicated syntax**
*   Python uses **easy-to-understand commands** that look almost like **English.**                                             ---                                                                                                                         Python is used in many real-world areas, including web development, data science, artificial intelligence, machine learning, automation, cybersecurity, and software development.
